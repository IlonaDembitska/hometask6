# Hometask 6 – Vagrant + VirtualBox + LVM
Дембіцька Ілона

## Опис
У цьому завданні створюється віртуальна машина на основі generic/ubuntu2204 з використанням Vagrant та VirtualBox.  
Під час запуску автоматично додаються 4 додаткові диски (по 400 MB), створюється LVM-структура, фізичні томи, Volume Group та два логічні томи, які монтуються у файлову систему.

## Автоматизація у Vagrantfile
Після виконання vagrant up конфігурація виконує:

1. Створення 4 додаткових дисків (по 400 MB).
2. Розмітку кожного диска (GPT + primary partition).
3. Створення фізичних томів (PV).
4. Об’єднання їх у Volume Group vgdata.
5. Створення двох логічних томів:
   - vol0 – 780 MB  
   - vol1 – 780 MB
6. Форматування томів у ext4.
7. Створення точок монтування:
   - /mnt/vol0
   - /mnt/vol1
8. Додавання записів у /etc/fstab.
9. Автоматичне монтування LVM томів.


## Як запустити проєкт
vagrant up
vagrant ssh

1. Перевірити підключені диски
lsblk

2. Перевірити фізичні томи LVM
sudo pvs

3. Перевірити Volume Group
sudo vgs

4. Перевірити логічні томи
sudo lvs

5.Перевірити файлову систему та монтування
df -h

6. Перемонтувати вручну (якщо треба)
sudo mount -a
